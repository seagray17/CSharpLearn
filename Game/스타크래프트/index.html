⚙️ 입력(Input) · 갱신(Update) · 렌더링(Render) 게임 아키텍처

1. 입력 (Input)

마우스 좌클릭(유닛 선택), 우클릭(목표 좌표 이동·채취·탑승 명령), 키보드(WASD 이동, C 은폐, B 잠복, G 채취, U 하차) 이벤트를 수집해 객체에 전달합니다.

2. 갱신 (Update - 다형성)

매 프레임(dt)마다 모든 Unit의 update(dt)를 호출합니다. ZergUnit은 체력을 자동 재생하고, ProtossUnit은 쉴드를 재생하며, IDetector는 반경 내 ICloakable 은폐 유닛을 실시간 탐지합니다.

3. 렌더링 (Render)

갱신된 객체 상태에 따라 render(ctx)가 캔버스에 그립니다. 은폐 시 반투명 처리, 탐지 시 붉은 스캔 링, 잠복 시 땅속 마커, 체력바(초록)와 프로토스 쉴드바(파랑)를 시각화합니다.

📦 Java 게임 루프 & 클래스 파일 다운로드 (통합 및 개별)

입력(Input)·갱신(Update)·렌더링(Render) 루프가 구현된 Java 소스코드를 통합 단일 클래스 또는 개별 클래스 파일로 내려받을 수 있습니다.
