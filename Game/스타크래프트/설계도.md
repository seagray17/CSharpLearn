# 클래스들의 관계도 표현

- 클래스가 많이 존재할 때 각 클래스가 어떤 관계를 갖고 있는지를 표현하는 것이다.

## 왜 (관계를 표현해야하나?)
코드의 공통적인 부분을 어떻게 줄이고 설계했는지

- 스타크래프트 24종의 클래스를 분리를 할 때 중첩되는 기능이 너무 많다.
- 이를 어떻게 해결할지 분석


## 무엇이 다른가 (상속과 인터페이스)

- 상속 : 부모님

- 인터페이스 : 약속


## 활용

- 유닛 클래스 : 체력, 이름, 이동, 지상인가 공중인가, 생체인가 기계인가 공통 기능을 갖는 추상클래스.

- 테란, 저그, 프로토스 클래스를 각자의 특성에 맞게 구현하라. 저그는 체력재생, 프로토스는 쉴드 재생
- ICloakable, IDetector, ITransport, IWorker, IBurrowable
- 다형성을 지켜서 코드를 C#으로 작성하라
- 하나의 클래스 안에 전부 다 만들어줘. program.cs
- 각 클래스는 다운로드 받을 수 있게 해줘
